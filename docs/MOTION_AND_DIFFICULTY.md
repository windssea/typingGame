# 0.7 动感与难度

训练选择页提供 0.65×、0.85×、1.0×、1.3×、1.6× 五档。速度调整动作玩法的移动、刷新和目标时限；无压力练习保持无倒计时，一分钟冲刺保持真实 60 秒。每次选择会保存，键盘焦点留在刚刚选择的按钮。

挑战提供进阶、高手、大师，对应 1.0×、1.35×、1.75× 压力。五款街机挑战的完成目标为 30/36/42；漏击伤害为 20/25/30。城堡挑战敌人生命为 1/1.2/1.4 倍，攻城伤害为 1/1.15/1.3 倍。冲刺挑战需要在 60 秒内达到 18/36/60 个正确字符及 85%/90%/95% 准确率。不同难度与非标准训练速度分别记成绩，旧版标准成绩继续兼容。

## 动画与反馈

拳手新增本机 Grok Build 实际生成的关节动作：蓝方和珊瑚方各有待机与命中出拳。保留原生 24 fps，不补帧；出拳由真实命中驱动。来源与提示词在 `assets/animation-sources/boxing-duo/`、`boxing-blue-solo/`。运行资源为蓝方 idle-v002、punch-v003 与珊瑚方 idle/punch-v001，未采用裁切到拳套的候选片段。

粒子包括命中星芒、碎纸、泥土、引擎尾焰、氮气和扩散光环，最多 280 个。飞船悬浮、地鼠弹出、气球摆动、赛车颠簸、敌人步态与受击后退采用程序动画。它们读取游戏状态，不阻塞输入；暂停冻结视觉时钟，减少动态效果模式关闭持续尾迹并显示固定拳手帧。并非所有角色都已拥有完整骨骼或逐帧动作。

游戏 HUD 使用得分、准确率、连击、体力四列与进度条，信息变化时刷新。卡片使用对应场景缩略图及真实角色素材，焦点/悬停/按下有轻微缓动。文字目标与粒子分层，避免文字跟随视觉抖动。
