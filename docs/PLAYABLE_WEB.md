## 课程到游戏

按 Enter 继续当前课，或进入「打字训练」选择课程。十课依次覆盖 F/J、少量键位、基准行、上排、下排、短词、长词、数字、Shift 与句子。每一课可以选不同小游戏。主入口只保留训练与挑战，首页Enter直接开始当前课程的推荐任务；准确通关后可继续下一课。底部固定显示完整目标与输入动作，五款动作任务用F3释放充能技能，详见 [0.8 机制](ADVENTURE_V08.md)。Tab / Shift+Tab 切换按钮，方向键选择，Enter 确认；游戏列表会跟随焦点滚动。

## 实际玩法

| 玩法 | 正确输入造成的变化 | 压力与目标 |
| --- | --- | --- |
| 星火练习场 | 完成目标并切换下一题 | 无时间压力，完成18题 |
| 字母泡泡 | 按首字母选中并点亮泡泡 | 多目标选择，完成18题 |
| 字母陨落 | 击破向下移动的字符 | 守住90秒，漏掉5次失败 |
| 一分钟冲刺 | 连续换题并计分 | 60秒测速度与准确率 |
| 守护键之城 | 施法伤敌、充能防御塔，连击释放雷电 | 六波敌人、两场Boss，城防归零失败 |
| 气球猎手 | 击破上升气球并触发爆破反馈 | 训练18个目标分三段；金色气球有额外奖励 |
| 外星攻防战 | 发射激光，三连击恢复护盾 | 拦截外星舰，护盾耗尽后损伤船体 |
| 打字打地鼠 | 命中随机洞口的地鼠 | 训练漏掉不扣体力；挑战有失败条件 |
| 键盘拉力赛 | 推进赛车，三连击后增加推进量 | 训练自由完赛；挑战先于对手冲线 |
| 指尖格斗馆 | 扣对手体力并打断蓄力，四击换对手 | 超时遭受反击，体力归零失败 |

切换英文输入法，照目标输入即可。Backspace 撤回，Tab 放弃当前锁定，Esc 暂停，F1 打开指法教练，F2 切换动作游戏音效，F3 释放充能技能。暂停中的指法图关闭后会返回暂停菜单。结算页可再练一次或返回大厅，也可按 Esc 返回。

## 城堡键盘操作

建设阶段：1–4 选基座，Q/W/E 建火焰/寒冰/雷电塔，U 升级当前塔，A/S/D 强化施法/连锁/城墙，R 修复，N 开波。金币不足时不会购买；战斗期间锁定建设。输入敌人上方字符会施法；盾卫和Boss需要多次命中。波次结束后赚取的金币可以继续升级。

## 存档与导出

学习进度、经验、结算成绩、易错键、偏好保存在当前浏览器站点的 IndexedDB。训练和挑战成绩分开记录。「学习档案」可下载 JSON 备份，再粘贴导入。不保存半局战斗，不含账号和跨设备同步。浏览器清除站点数据会删除本地存档。

## 实现与验证入口

`scripts/main.gd` 是真正的页面与输入入口。`game_run.gd`、`arcade_run.gd`、`castle_run.gd` 执行玩法规则；场景绘制读取同一个运行状态。`tools/check-web-runtime.cjs` 用独立 Edge 配置和真实浏览器按键测试 Web 构建；只有 URL 带 `?qa=1` 才启用只读状态观察桥，观察桥不提供游戏指令。截图与机器报告在忽略提交的 `build/runtime-qa/`。

可将 `build/web/` 整个目录上传到静态主机。当前已在 Cloudflare Pages + R2 实际发布，并验证公网启动、键盘训练结算和刷新存档；未完成所有浏览器兼容性验证。
