# 指尖挑战 0.9

产品主入口仍是「打字训练 / 打字挑战」，公开名称统一为「指尖挑战」。引擎内部项目名称保留旧值，以沿用桌面及网页既有存档命名空间；窗口标题、浏览器标题、首页和加载文案使用新名称。

## 词库与教学

- 709 个不同的核心词、24 个生活主题、48 条原创短句。数据在 `data/a2-vocabulary.json`，中文释义与主题由本项目独立编写，可通过 `tools/build-a2-vocabulary.py` 重建。
- 参考资料为 Cambridge 官方《A2 Key and A2 Key for Schools Vocabulary List》，August 2025：https://www.cambridgeenglish.org/Images/506886-a2-key-2020-vocabulary-list.pdf 。这是 A1–A2 / KET 衔接训练词库，不是完整官方词表，也未经历年试卷逐词频次统计；不能宣称已验证为“709 个历年真题高频词”。
- 用户确认采用自行整理的核心训练词方案。不会自动抓取或复制第三方试题、释义及例句。
- 前五课仍只使用本课的指法键位，第八课仍练数字；第六课使用 2–4 字母词，第七课使用 5–12 字母词，第九课练大小写，第十课练短句。专名仅在大小写课使用。
- 训练任务与挑战页面右下角进入词库，用 Tab、Enter、方向键操作主题选择。所有小游戏从同一份课程数据取词；底部显示当前词义与刚完成的词。
- 打乱词袋在一个周期内不重复，并尽量避开同屏相同首字母；相同紧急程度用目标 ID 固定排序。词牌、底部提示及指法教练使用同一推荐目标，输入首字母锁定后保持目标。
- 主题偏好随存档保存，旧档无需迁移；A2 主题成绩使用独立后缀，保留旧成绩。基础课程掌握规则不变。

## 十种任务的动作变化

| 名称 | 本轮变化 |
| --- | --- |
| 指尖发射站 | 逐键挥臂与关节动作、键帽按压、18 格进度环；长句自动缩字，已输入部分与下一字符明确标出 |
| 泡泡啵啵乐 | 轻微浮动形变、水滴破裂、18 颗收集标记；四个泡泡使用六处位置，换题避开原地爆破 |
| 流星拦截队 | 流星粒子尾迹、跟随目标的拦截器与逐键光束、补齐原先遗漏的命中粒子绘制；长文本有足够飞行时间 |
| 极速 60 秒 | 平滑速度表、每个字符推进跑道小人、计时进度；长文本适配大字区域 |
| 魔法城堡战 | 防御塔冷却环、发射后坐与恢复、锁定准星、较大词牌与稳定避让、清楚的连线；长文本降低敌人移动速度 |
| 气球蹦蹦节 | 输入过程逐步充气、完整输入爆破、目标周边充能弧；词牌在特效之后绘制 |
| 星际闪电战 | 炮口逐字充能、瞄准粒子、激光与护盾反馈；被击中飞碟向下退场，避免隐藏新目标 |
| 地鼠敲敲乐 | 通过裁切从洞口露出完整比例角色，前景洞沿遮挡、逐字举锤、落锤轨迹；连续地鼠不出在同一个洞 |
| 疾速拉力赛 | 规则位置与画面位置分开，指数平滑推进赛车、能量仪表、尾迹跟随画面位置；技能仍实际影响对手赛程 |
| 连击小拳王 | 逐字蓄势弧与动作线、原生出拳动作、命中停顿只作用于姿态、黄色残血条缓动；格挡提示持续到生效 |

保留已有本机 Grok Build 原生帧动画，本轮新增动作采用 Godot 程序动画、裁切、缓动与粒子，没有把这些程序效果描述为新生成的视频。减少动态设置保留可读的静态信息；暂停冻结规则与动效，输入不会被角色的命中停顿阻塞。

## 边界

这是实现与回归验证结果，不是儿童试玩研究结论。词义是训练用简释，部分词有其他含义；不替代完整词典或考试课程。网页进度仍按浏览器及域名保存，同一设备的 pages.dev 与自定义域名不是共享存档；可导出备份转移。
