# 1.2 · 场景里的游戏 UI

2026-10-20。按最新反馈继续使用明亮、轻盈的美式卡通风格，重点解决大片白底、标题挤压、按钮重叠与布局不稳定。旧设计文档仅作视觉参考，不将其中的评审流程当作用户授权要求。

## 视觉与操作

- 首页保留训练、挑战两条路径，以现有高清花园、星空场景和原生角色动作构成入口。插画底部有连续的材质过渡，文字独立于复杂背景；取消大块空白和旧的标题白框。
- 全局按钮采用暖金主操作、浅蓝次操作；细边、轻阴影、深色文字、蓝色键盘焦点。主题集中在 `PlayTheme.ui`，主按钮使用 Theme variation，避免逐个复制样式。
- 课程按阶段使用薄荷、浅蓝、麦黄、淡紫色训练牌，保留编号、掌握星章、当前选择勾号。任务牌保留场景、角色、名称、胜负条件和开始操作，删除重复输入示例。
- 存档与设置变为“我的冒险营地”：训练室背景、实际播放原生动画的教练、分开的音乐/音效滑条、备份操作和易错键。不再以白色后台表格呈现。
- 游戏内使用单条紧凑 HUD；指法、声音、暂停按钮同排。场景和输入栏之间保留间隔，下一键、完整输入词和词义不改小。状态条、指法区、词牌和输入台改用与场景协调的浅色材质。
- 暂停、成绩、导入、词库和 F1 使用统一的居中游戏面板。F1 规则不再叠加两层重复底框。

## 实现

`GameShell` 使用全屏锚点、Margin/VBox/HBox 容器组成标题区、场景区、助手区与输入台。保留现有模拟世界坐标，避免 UI 重排改变敌人位置和命中逻辑。首页、侧栏、课程、任务、设置及主要对话框使用容器；场景内的绘制坐标和旧城堡指挥面板仍按游戏参考坐标绘制，不宣称每个内部控件都已完全迁移。

参考分辨率仍为 1440×900，canvas_items 等比适配，其他宽高比留边。桌面实体键盘优先；本次没有重新设计手机竖屏。1280×720 窗口的有效内容为1152×720，1920×1080为1728×1080，1920×800为1280×800；原生 Viewport PNG 不包含窗口外侧黑边。

修复 Container 中的按钮默认抢占横向剩余空间的问题，固定尺寸按钮保留合理宽度，文本和弹性空白吸收剩余宽度。输入栏仍是1360×108；助手的任务说明限制在剩余高度内，避免把底栏推出画布。

`screen_stack` 保存每层面板、被覆盖控件的焦点模式和上一个焦点。帮助可以压在暂停页上；弹出帮助后仍暂停，Esc 再弹出暂停页才继续。Tab 限制在当前层，菜单提供明确的前后及空间方向邻居；课程选择重建后保留该课程焦点。

HUD 不再由主循环逐帧刷新。GameRun 的分数、命中、连击、体力、波次、整秒变化等通过 `hud_changed` 通知；赛车进度按0.5%粒度通知。同一批变化合并为一次 deferred 刷新。场景动画仍按帧绘制，其他部分的视觉缓存不在此轮承诺全部事件化。
