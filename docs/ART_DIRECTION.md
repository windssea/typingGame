# 0.5 美术制作约定

> 已被2026-10-19的 [五世界设计系统 v2](design-v2/DESIGN_SYSTEM.md) 取代。本文件保留为上一轮素材制作记录，不再指导新资产风格。旧版生成场景标为legacy，须按新样张审核后再决定重制或复用。

目标：儿童键盘游乐园，十个小游戏各有真实生成的场景素材；核心输入和指法标签由 Godot 绘制，不能烘焙进图片。

- 引擎：Godot 4.7.2 / Compatibility，1440×900 逻辑画布；游戏场景约 1040×650。
- 风格：精致玩具绘本，圆润轮廓，柔和体积光，奶油色高光，纸张/黏土质感，明亮现代，不使用黑暗恐怖或写实武器。
- 配色：天空蓝、薄荷绿、暖黄、珊瑚粉、淡紫；深蓝灰只用于必要轮廓和字。
- 背景：每个游戏一张横向场景，中央活动区域低细节，装饰集中边缘；无文字、UI、目标标签或水印。
- 活动素材：透明精灵图集，固定网格，足够间隔；用 AtlasTexture 切片，不删除/伪造透明背景。地图、碰撞与单词标签不依赖图片中的物体位置。
- 场景摄像机：气球/陨落/泡泡为正面；外星/城堡/地鼠/赛车为俯视或浅俯视；格斗为侧面；练习场/冲刺为面向屏幕的训练空间。
- 像素与内存：先检查生成实际尺寸/alpha；线性过滤，非像素画；背景运行期统一降采样到 1040×650 上限，源文件保留。仅缓存当前场景背景，图集按实际需要加载。
- 资产目录：`assets/generated/`；完整提示词和生成来源记入 `assets/generated/manifest.json`。
- 验收：真实生成文件存在、alpha/网格可用、素材覆盖十种模式、原生截图检查、全键盘路径和性能抽样；不将静态精灵称为逐帧动画。

键盘操作约定：菜单方向键/Tab 选择、Enter 确认、Esc 返回；战斗字母只用于打字。F1 指法，F2 音效，Esc 暂停。城堡准备阶段支持数字选基座和字母建设快捷键，战斗阶段不拦截这些字母。弹窗必须困住焦点，并在关闭后恢复。
