# 0.8：从找游戏转向学习与行动

本版把主路径收束为「打字训练」和「打字挑战」，移除五世界大厅、游戏集合、玩法图鉴及其入口。存档与设置是辅助工具。小游戏是训练/挑战的任务场景，不再作为第三条产品主线。

## 让输入有目的

每次输入都应回答三个问题：现在打什么、打对后发生什么、完成什么算赢。

- 场上蓝色词牌与箭头标记推荐目标。底部固定显示完整文字、下一枚按键和「输入完成 → 行动」，与右侧指法教练读取同一目标。输入其他目标首字母仍可主动选择；锁定后保持跟随。
- 挑战任务卡直接展示本课输入示例、动作和具体胜负条件。计时、城防、竞速和击破目标分别描述，不把一套目标文案套给所有任务。
- 首页 Enter 直接开始当前课的推荐训练。第一课进入 F/J 地鼠任务，课程页仍可改课程与任务。准确通关且达到18个正确字符后，可直接继续下一课。

## 训练有短阶段与奖励

地鼠、气球、外星、格斗训练缩短为18次完成，分成三段，每六次提供阶段反馈和充能奖励。地鼠训练仍允许无限漏击；基础练习与泡泡仍不限时；赛车保留24次目标，避免提前冲线导致基础课正确字符不足18。城堡和计时玩法沿用各自规则。

目标不会因动画暂停而拒绝输入。短暂停顿只冻结角色姿势，规则、键盘输入、计时和粒子继续运行。暂停菜单冻结角色与特效；减少动态时使用固定待机帧、较少粒子并关闭 HUD 缓动。

## 玩家可以做决定

每完成一个目标获得一格能量，三格后按 **F3** 释放技能；技能不计入输入尝试。浏览器壳拦截F3默认查找操作。冷却与生效时长在底部展示。

| 任务 | F3 的实际效果 | 目标选择 |
| --- | --- | --- |
| 气球 | 四秒内目标时间消耗降至20% | 金色气球额外40分与一格能量 |
| 外星攻防 | 恢复12护盾，同时减缓四秒进攻 | 补给舰输入后恢复8盾；侦察舰时限短20% |
| 打地鼠 | 四秒内目标时间消耗降至20% | 奖励地鼠额外40分与能量 |
| 赛车 | 对手进度退后8% | 稳定连击自动氮气加速，手动技能用于追赶 |
| 格斗 | 格挡下一次反击 | 根据对手蓄力决定何时保留或使用格挡 |

F/J等词库很小时，同时出现的气球/UFO数量不超过不同首字母数量，避免两个目标要求同一个首字母而无法明确选择。补给与阶段奖励由规则层执行，不依赖特效组件存在。

## 实际生成的动作

本机 Grok Build 生成四条图生视频源片，均实测720×720、24fps、193帧、约8.04秒。原有 Image Gen 图集裁取已登记区域，统一画布后作为固定首帧；使用洋红背景保留绿色外星人、赛车和哥布林，不补帧。八个运行片段合计282帧：

- `assets/animations/mole-idle-v08/` 与 `mole-hit-v08/`：眨眼、抬爪、护头与回缩反应。
- `assets/animations/ufo-idle-v08/` 与 `ufo-hit-v08/`：驾驶员操纵、触角、表情和低头反应。
- `assets/animations/rally-drive-v08/` 与 `rally-boost-v08/`：玩家赛车轮组、悬挂与加速变化。对手仍使用原有贴图与程序动作。
- `assets/animations/goblin-walk-v08/` 与 `goblin-hit-v08/`：交替迈步、手臂摆动与受击动作；其余城防敌人仍沿用原有程序动作。

母版、动作提示词、无声预览和任务状态在 `assets/animation-sources/*-motion-v08/`。完整原片与原始本机收据在忽略提交的 `build/animations/`。源工具未返回独立服务请求ID或服务模型名，状态文件不以CLI会话ID冒充。部分短待机循环仍可能有接缝，未声称所有角色拥有完整动作库。

## 验证边界

`tests/interactive_training.gd` 的38个断言覆盖直接进入推荐训练、两条主路径、指法与目标一致、原生帧播放、一次性动作不回卷、按F3真实释放、充能、减速/补盾/干扰/格挡效果、暂停冻结、18次训练掌握与下一课。

既有回归为基础734、城堡45、街机601、守卫动画12、UI23、街机UI40、难度与动效33，均通过。断言数不是独立玩家场景数。原生实际界面截图在 `build/v08-*.png`；自动化技能截图中的输入来自测试事件。尚未做儿童试玩研究，不将动画数量或自动化通过视为已经证明“有趣”。
