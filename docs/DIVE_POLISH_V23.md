# 2.3｜深蓝潜艇队

本轮将玩家艇、侦察艇、装甲艇和补给舱分为可识别的美术与行为角色，保留原海底场景与稳定词牌锚点。

## 操作与真实事件

- 敌艇从右侧屏幕外驶入，不在画面中间刷新。普通艇一词命中即拦截；装甲艇以独立金色厚甲外形、装甲段和词牌血量提示多次命中，普通／高手两次、大师三次。
- 完整输入发射追踪鱼雷，伤害、破甲、敌艇退场和已发射威胁的解除等待实际接触。完成输入后的临界拦截不会因敌艇刚到左边界而扣血，也不会把艇突然移回安全区。
- 挑战敌艇使用巡航、蓄势与已发射状态。蓄势有按词长和难度计算的明确窗口、原生灯光与动作；完成单词可打断未发射攻击。来袭鱼雷沿真实弹道移动，抵达玩家后才造成一次伤害。训练不引入敌艇主动射击。
- 补给使用独立压力舱素材。救援探针接触后拖回玩家艇，抵达时才恢复 12 体力、计分、充能与触发最终胜利。不会在补给舱位置播放敌艇击毁动画。
- 空格声呐同时影响敌艇与来袭鱼雷，保留 12% 的缓速；画面以海水扫描、艇身冷色及局部水波反馈技能范围。词牌和 HUD 保持原位。

## 美术与引擎表现

内置 ImageGen 生成同家族侦察艇、装甲艇、压力补给舱、敌我鱼雷和鱼群。三条本机 Grok Build 原片实际均为 960×960、24fps、193 帧，保留原片，不插帧、不复制姿态图。运行使用六组 384px 帧图集，角色画布原点统一。命中与退场按短反馈时钟采样原生姿态，不生成中间帧。

首条装甲艇视频后半段带有简报禁止的火花；运行只取其无火花的巡航与蓄势区间，受击改用重新生成的干净动作。素材源、原始回执中的已知字段、哈希、时间区间与提示词见 [ANIMATION_V23.json](ANIMATION_V23.json)。生成器的网格并不精确，四件海底道具采用实际测量的独立区域，逐项检查透明边界。

Godot 负责四组有界 CPUParticles2D 航行气泡尾迹、六组可复用飞行拖尾、三盏敌艇信号 PointLight2D，以及接触粒子、水波与背景轻震动。灯光仅影响场景层。海底背景增加受游戏时钟控制的折射、焦散与声呐扫描；暂停时停住，低动态设置关闭非必要移动／闪烁。鱼群替代潜艇场景中的三角形占位鱼。

海底深色珐琅词牌改用浅色描边字，保留上一轮最小尺寸、字距与角色相对锚点。装甲提示、艇身状态和粒子不改变文字大小或横向位置。

## 验证边界

60 项模拟检查覆盖 30/60/120fps 下的蓄势打断、鱼雷接触、重复伤害防护、装甲多次命中、补给拖回、暂停、声呐与左边界拦截。483 项素材／原生特效检查覆盖六套动作、高清画布、道具裁区、透明边界、尾迹／灯光池及低动态设置。另执行 20 套既有回归、116 个页面／分辨率状态与 13 个隔离分包启动。

原生渲染分别截取交战、命中、声呐和补给场景，网页另用真实键盘操作验收。性能报告仅描述当前本机原生环境，不推广为浏览器、手机或所有硬件的帧率保证。高清潜艇分包约 14.73 MB，进入潜艇时按需下载；首页启动包 gzip 约 3.95 MB。
