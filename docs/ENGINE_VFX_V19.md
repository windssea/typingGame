# 1.9 引擎原生特效

本轮覆盖全部 13 种玩法，保留现有 Grok 角色动画，新增 Godot 原生场景反馈。没有增加需要下载的视频或大幅素材。

## 实现

- `EngineVfx`：各竞技场共用的原生反馈层，直接订阅真实的发射、命中、技能、建塔和桥梁修复事件。界面和计时不等待动画。
- `CPUParticles2D`：爆发火星、上扬彩屑、土尘、水花、蒸汽、环境微粒和跟随物理炮弹移动的尾焰。采用 CPU 粒子以适配项目现有 Compatibility / Web 渲染器。
- `PointLight2D`：炮口、碰撞和魔法的短暂局部光照，真实影响背景材质。灯光只使用第 2 光照遮罩，打字目标和 HUD 不受光照染色。亮度在 0.25 秒内衰减。
- Godot Tween：冲击波展开、灯光衰减和短促景深背景震动；强度分级，背景位移上限 3 个参考像素，通过预留采样边缘避免露底。角色沿用独立视觉受击反馈。轻反馈不触发震动。
- CanvasItem 着色器：短暂冲击波、格斗斩击弧、水下扩散波。所有特效材质共享单词保护区域，最多 32 个区域，避免覆盖字母。
- 城堡四个塔位各自配备原生粒子发射器，建成后按火、冰、电属性显示持续能量。

| 场景 | 新增反馈 |
| --- | --- |
| 流星拦截 / 城堡 / 潜艇 | 炮口局部光、跟随实际炮弹的原生尾焰，接触时的爆发与波纹 |
| 气球 / 地鼠 | 弹开的碎屑、上扬粒子、土尘与重击短震 |
| 格斗 / 皇家战 | 接触光、方向弧光与分级受击反馈 |
| 赛车 / 极速 60 秒 | 推进喷光、加速粒子和阶段连击反馈 |
| 餐厅 | 锅台蒸汽、出餐闪亮反馈，粒子位置贴近餐盘 |
| 泡泡 / 外星人 / 星桥 | 水花、引擎光、桥梁修复火花与阶段庆祝 |

## 资源与暂停

每个竞技场固定复用 10 个爆发发射器、6 个弹道发射器、5 个灯光和 6 个冲击波节点，另有 1 个环境发射器。城堡最多额外 4 个塔位发射器。密集触发只复用已有节点，不持续实例化节点。单个爆发最多 30 粒，弹道发射器各 20 粒，环境 20 粒，塔位各 12 粒。

暂停将粒子速度设为 0，并停止推进 Tween、光照和背景震动。减少动态设置隐藏运动粒子和轨迹、禁用局部光闪与震动，仅保留短暂、原地淡出的柔和确认。全程不修改 `Engine.time_scale`，不改变游戏物理位置、输入、伤害或计时。

## 验证

- `tests/engine_vfx_tests.gd`：148 项，覆盖所有玩法的真实事件接线、节点池、物理发射、暂停、资源复用、恢复与减少动态。
- `tests/vfx_render_tests.gd`：真实 Compatibility 渲染器下 12 项像素验证，分别测试气球、城堡、潜艇。比较冲击波前后保护区域与周围像素，并验证 PointLight2D 改变了背景像素。
- 既有 18 套测试：30,886 项通过，未发现脚本错误。
- 本机性能采样带额外重击效果，不能外推至所有浏览器或移动设备。结果及原生截图保存在 `docs/ui-review-v19/`。
