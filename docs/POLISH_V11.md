# 1.1 大字输入、高清动作与画面清理

2026-10-20。沿用明亮、圆润的美式卡通方向，主路径仍为打字训练与打字挑战。

## 输入优先

- 底部固定输入栏增至108像素高。完整单词优先使用46号粗体，下一键49号，长句最低32号并按实际字宽换行；保留每个空格、大小写和标点。当前字母使用暖金色底与下划线，完成部分用深薄荷色，错误保留进度并明确变色。
- 词牌统一使用测量、换行和避让布局。推荐目标先分配位置，再避开其他词牌、角色和战场状态条；密集城堡增加全场空位搜索。角色与文字分层，文字保持稳定，震动、变形、镜头背景材质不作用于文字。
- 所有模式在粒子与打击反馈之后绘制词牌。粒子增加文字保护区域；固定输入栏与场景、指法按钮和建造按钮保持间距。没有增加常驻规则小字。

## 清晰度和动作

23个旧动作图集从原始Grok视频重新解码为256/384像素单元，保留原生帧率、区间、帧数与锚点，不是放大旧128/192图集。新增教练的待机、庆祝、原地跑步三组384像素动画，总计26组活动图集。原始角色视频为720或960像素，静态游戏背景原图1536×1024；没有将它们称作原生4K素材。

新教练由 built-in Image Gen 生成：`assets/generated/coach-mint-v11.png`，实测1214×1295透明RGBA。完整生成方向记录在 `assets/animation-sources/coach-motion-v11/seed-provenance.json`，动作提示词在 `motion-v001.txt`。本机Grok Build单次提交，原片实测960×960、24fps、193帧、8.041667秒；无声归档 `source-silent.mp4`，游戏取待机48帧、庆祝42帧、跑步48帧，没有补帧。闭眼、弯膝、跳起与摆臂动作已查看接触帧和实机表现。

高清图集启用mipmap，仍使用无损纹理导入和透明安全边距；拳手资源在格斗开始时载入，守卫资源在城堡开始时载入，菜单仅载入预览待机。Web导出排除旧图集副本，Git保留源文件与历史资源。23个重建图集最小透明边距10像素。最终波城堡图集解码RGBA约154.5MiB，未将桌面测试等同低端移动设备内存验收。

## 动感与线条

- 泡泡水滴、气球花瓣与短暂塌缩、地鼠土屑与挥锤、赛车定向尾流与悬挂回弹、拳手冲拳与击退、城堡元素碎片与敌人受击退场。短暂停顿只影响角色动作，下一次输入继续接受；粒子总量仍限制280个并自动回收。
- 场景背景独立材质提供云层缓移、边缘植被微动、光影和悬挂物轻摆；地面与角色规则不跟随背景变形。暂停冻结时间，减少动态关闭背景运动和定向粒子。
- 清理陨石网格、发射站大辅助圆环、重复泡泡描边和战斗中空塔基标记。地鼠洞口改为带渐变深度和前缘遮挡的高分辨率SVG。连接线、射线和必要圆弧用抗锯齿与圆端描边；删掉各类命中通用的多重粗放射线。Compatibility/GLES3实测不支持2D MSAA，已撤回无效设置，依靠实际支持的纹理采样与逐笔抗锯齿。

## 验证边界

新增184个无显示检查通过，覆盖长句完整性、词牌避让、输入栏间距、十模式真实键盘完成、素材尺寸、动作/粒子、暂停、回收、减少动态和拥挤城堡。原生OpenGL执行192检查通过，额外8个像素比较确认粒子直接在词牌中心爆发也不改变词牌内部画面。截图覆盖十模式、命中、密集城堡和长句，在 `build/v11-*.png`。原有十组23999检查继续通过。

这些检查不等同儿童试玩、逐帧美术人工签核或低端设备全面性能验收。字体仍为可缩放Noto Sans SC子集，教学指法仍是确定映射，未用生成图猜测手指负责的键位。
