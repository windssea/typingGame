# 页面与键盘交互规范 v2.0

## 1. 信息结构与主路径

世界大厅 → 训练课程 → 本课选择玩法 → 开局说明 → 游戏 → 结算 → 下一次练习。

世界大厅 → 挑战大厅 → 选择词库/节奏/游戏 → 开局说明 → 游戏 → 挑战结算。

大厅保留学习档案、设置与指法入口。五世界是题材入口，十课程是学习进阶，十游戏是规则集合；三者不混成同一条解锁树。第一天推荐F/J与无压力玩法，不硬锁高阶内容。

| 页面 | 主要结构 | 主动作与默认焦点 | 返回 |
|---|---|---|---|
| 世界大厅 | 品牌顶栏、继续学习台、五世界入口、本世界玩法 | 继续本课 | Esc无跳转，仅说明当前在大厅 |
| 训练课程 | 四学习阶段、十课程节点、当前键位与目的、已掌握标志 | 当前推荐课程节点 | 回大厅并恢复入口焦点 |
| 本课选玩法 | 明确课程来源、无压力推荐、十游戏、节奏开关 | 推荐无压力玩法 | 回课程原节点 |
| 挑战大厅 | 与训练明确分离、当前词库、模式、风险提示 | 选中的模式/开始挑战 | 回大厅挑战入口 |
| 开局说明 | 本局练什么、打字产生什么动作、失败条件、键盘提示 | 开始本局 | 回原玩法格 |
| 通用游戏 | 顶部目标与状态、中央场景、稳定词牌、可折叠教练、底部操作提示 | GameplayInput捕获文字，不给普通按钮残留焦点 | Esc推入暂停 |
| 城堡准备 | 场景基座、右侧建设面板、资源与下一波信息 | 当前基座/建塔动作 | Esc推入暂停 |
| 暂停 | 继续、指法、设置、结束本局 | 继续 | Esc继续；离开未结算本局需清楚说明 |

| 学习档案 | 训练掌握、挑战记录、易错键、存档状态 | 继续推荐训练 | 回大厅档案入口 |
| 导入 | 替换说明、粘贴区、校验结果、恢复与取消 | 取消；验证通过才允许恢复 | Esc取消，不改存档 |
| 设置 | 声音/减少动态/文字大小/教练/备份 | 第一设置行 | Esc保存可逆偏好并返回 |

## 2. 页面线框尺寸

桌面1280×800基线，安全边距32；顶栏80，底栏56。大厅内容区1216宽，五个世界入口均分（间隔16），每个≥192宽、约248高。继续学习为宽面板，左文字右进度示意；同时只突出一个主动作。游戏入口采用响应式3列，窄屏2列，滚动容器跟随焦点自动露出目标。

游戏：顶状态区80，中央舞台与右侧教练（约3:1），底部输入/提示区。城堡准备右栏为基座→塔→强化→开战的顺序；开战后右栏切换目标简报，收起建设按钮，不让字母快捷键与词输入同时生效。

Boss警报占顶部第二行，不遮中央要塞；目标词牌包含血量和蓄力，优先避让后再用引线；极密集时限制同屏目标而不是让标签无序叠放。

## 3. 键盘状态机

输入上下文：`MENU → INTRO → BUILD → PLAY → PAUSE/GUIDE/SETTINGS → RESULT`。只有栈顶接收输入。结束、导入错误、失焦必须有明确状态，不用多个互相覆盖的布尔值推断。

| 上下文 | 键 | 行为 |
|---|---|---|
| 菜单/弹窗 | 方向键 | 几何邻居导航；页签区域左右切换，网格上下左右移动 |
| 菜单/弹窗 | Tab / Shift+Tab | 顺序前后移动；模态内部闭环；不滚到看不见的焦点 |
| 菜单/弹窗 | Enter / Space | 激活当前控件，单次按下执行；按住不重复购买 |
| 全局 | Esc | 弹窗返回/关闭；游戏暂停；栈为空回大厅；不直接丢弃有效存档 |
| 游戏 | 可打印字符 | 只输入目标；使用字符而非硬编码物理键产生文字符号 |
| 游戏 | Backspace | 撤回当前目标最近一次输入，统计保持既定规则 |
| 游戏 | Tab | 切换目标，按实际玩法决定是否取消锁定；不进入菜单焦点 |
| 游戏 | F1 | 打开/关闭指法并暂停；关闭后恢复打开前的暂停状态 |
| 游戏 | F2 | 音效开关，提示当前状态；声音操作不抢文字焦点 |
| 城堡准备 | 1–4 | 选基座；显示原塔和下一动作 |
| 城堡准备 | Q/W/E | 火/冰/雷建塔；不足时反馈差额，不执行购买 |
| 城堡准备 | U | 升级当前塔；满级明确显示，不沉默 |
| 城堡准备 | A/S/D | 火力/连锁/城防强化；解释实际增益与费用 |
| 城堡准备 | R / N | 修复 / 开始下一波；N只接受新按下事件 |
| 游戏结束 | Enter | 激活当前结算动作，防止最后一个单词的尾键穿透 |
| 文本编辑 | 常规编辑/粘贴 | 交给TextEdit；所有字母快捷键停用；Tab离开文本域 |

网页快捷键可能与浏览器冲突；仅在游戏画布持有焦点时拦截F1/F2/Tab，不全局屏蔽浏览器。点击外部、Alt+Tab或窗口失焦暂停；重新聚焦不自动开战，默认停在“继续”。中文输入法组合期间不判错，显示“请切换英文输入”；组合结束后再判断课程字符。

初次开启指法教程的动画不强制重播。双手示意是教学图，不检测摄像头或真实手势。键区同时有手指编号与颜色；大小写和符号显示主键+对侧Shift，Space由拇指表示。

## 4. 焦点与危险操作

每个页面记录`screen_id + focused_control_id + scroll_position`。进入默认焦点，返回恢复原位置。购买导致重建控件时保留语义ID，原控件失效则回相邻可用动作；禁用项不能成为死路。选中与聚焦视觉分离，方向移动不立即更换课程或花金币。

弹窗压入时背景控件停用输入，焦点只在弹窗内；关闭恢复旧焦点。导入、重置或放弃本局等需后果明确，默认焦点放在安全选项，不将危险确认绑为裸字母快捷键。

## 5. 教学与目标反馈

基础课一次只突出少量键；先展示F/J凸点，再演示手指回位，再允许练习。后续依次扩展DFJK、基准行组合、上排、下排、短词、长词、数字、Shift、句子。具体词库继续复用`data/curriculum.json`，不由主题美术编造新的练习符号。

无压力与有限压力明确标记。准确率与有效输入量用于掌握评定，WPM解释为有效输入速度。训练和挑战结果分开保存；世界切换不清空成绩。失败页优先一项可执行建议，避免五个指标同时批评玩家。

## 6. 空、错、禁用与存档状态

- 未选择课程：推荐当前课程并解释目标键，允许切换。
- 未有成绩：给开始训练入口，不显示“0分排名垫底”。
- 资源不足：说明“还差20金币”；满级说明“已达最高等级”。
- 音效不可用：图标与文字继续反馈，不让音频初始化阻塞输入。
- 资产未完成：原型明确标注示意；生产构建采用可见占位和错误日志，不隐形单位。
- 存档：保存中、已保存、保存失败分别显示；网页持久化不可用时提供导出。不要宣称跨设备同步。
- 导入：格式错误保留当前学习记录；校验通过后显示将恢复的课程与记录数量，再确认。

## 7. 原型交付与演示范围

`index.html` 支持五世界皮肤切换、大厅、课程、十游戏、训练/挑战开局、城堡准备、示例键入、指法、暂停、结果、档案、设置和按钮状态展示。五世界同一功能布局用于检验“换主题不换交互”。

原型的键入只驱动本页演示计数；没有真实敌人AI、计分可信度、完整词库、云存档或网页Godot打包。UI偏好仅存于独立的`keybound.designV2`本地键。美术样张是方向参考，不等于完整可切片精灵库。
