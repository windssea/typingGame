# v2.1 · 轻松明亮的界面

根据用户“整体UI太厚重了，颜色更轻松”的反馈，本次修订界面表现；五世界、学习路径与键盘交互继续复用。

| 层级 | v2.1默认表现 |
|---|---|
| 页面底 | 极浅天蓝与温暖白，少量柔和渐变 |
| 导航 | 白色轻透顶栏、浅蓝当前页签 |
| 普通面板 | 白色阅读面、1px边界、轻柔扩散阴影 |
| 主按钮 | 浅杏色、深棕文字、2px按压深度 |
| 次按钮 | 白色、深蓝灰文字、淡蓝悬停 |
| 世界入口 | 插画保留色彩，底部改为白底深字，减少暗部遮罩 |
| 课程与玩法格 | 白底，浅蓝/薄荷/奶油/淡紫区分，不叠重型外框 |
| 城堡HUD | 白底指挥面板、浅杏资源槽、轻边词牌 |
| 指法教练 | 白色键帽、2–3px键底、浅杏高亮、蓝色定位线 |
| 弹窗 | 白色内容、柔和半透明遮罩，不压暗成黑蓝舞台 |

全局语义和文本仍用足够深的颜色，不能为了轻松把正文洗成浅灰。焦点使用蓝色外环；选中使用底色、边框和◆，保留非颜色线索。48px热区和字号不因减重而缩小。

实现：浏览器默认加载`light-theme.css`，作为明确的v2.1项目外观覆盖；原`prototype.css`保留布局与v2历史基底。解析Tokens记录项目边框、按钮深度和五世界浅底；输入的五世界参考JSON未改写。Godot的`PlayTheme`、通用按钮和动画预览标题同步采用浅色方案。

原始角色、建筑与场景图仍保持母风格的体积和材质。本轮调整UI的画面占比、颜色和层次，不把角色形体变成扁平图标。
