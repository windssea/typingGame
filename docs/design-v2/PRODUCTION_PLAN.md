> 0.6 实施更新：世界入口图与皇家战场已复制到 `assets/worlds/` 并接入实际 Godot 游戏。五种街机玩法和城堡已新增透明角色/塔图集，区域与来源记录在 `assets/generated/`。战场仍是含要塞的整张背景，尚未拆成可编辑地图层；下文的完整分层生产目标仍保留。实际玩法与验收见 [网页可玩版](../PLAYABLE_WEB.md)。

## 1. 资产审计

上一轮 `assets/generated/` 的十场景与气球早期稿标记为 **legacy / 玩法调试参考**。它们能验证空场与词牌构图，但偏高饱和插画、花草细节较密，缺少五世界独立身份；不能直接认定符合新母风格。保留文件以便对比，不作为新生产的唯一风格锚点。

`assets/design-v2/five-world-benchmark.png` 是本轮内置 Image Gen 生成的**概念样张**：比对大体块、材质概括、各世界轮廓。它有较多场景细节，适合大厅世界入口，不适合直接当满屏战斗底图。完整提示词与来源见同目录 `provenance.json`。

`assets/design-v2/royal-battlefield-benchmark.png` 是第二张样张，依据五世界图中的皇家材质方向生成，并接入城防原型。要塞烘焙在概念底图中，四个建设槽与词牌仍由交互层提供；正式生产需拆出要塞、塔与环境层，并重新匹配真实游戏坐标。原型使用等比cover取景，不能将概念图裁切位置当作正式地图数据。

本轮不批量沿用旧风格生成其余精灵。先以同屏主体+背景+词牌+UI组件确认视觉，再按家庭生产；不因生成了一张大图就标为生产就绪。

## 3. 图像技术规范

背景建议1536×1024或2048×1280源图，按实际舞台比例构图；运行期与导入预算按目标设备实测。角色源图512×512透明；需要逐帧时按职业统一锚点与留白，勿假设生成图集自动等间距。VFX独立透明层；UI外框九宫格，透明区与文字安全区清楚。

线性过滤，按缩小比例测试mipmap；色彩贴图sRGB，alpha边缘检查深/浅底。普通角色在96逻辑单位显示时仍需读出职业；不要通过加载4K肖像掩盖剪影不清。

纹理内存计算为解码尺寸×通道，而非PNG文件大小。一次战斗只保留当前背景、当前世界图集、Core UI与必要字体；离开释放世界私有资源。背景压缩、图集尺寸、帧数与VFX粒子上限需在Web导出实机测试后冻结。

## 4. Godot 迁移结构

```text
CoreTheme + SemanticTokens
ThemeRegistry (royal/scifi/modern/ancient/fairytale)
ScreenStack (输入权/暂停快照/焦点ID/滚动位置)
  WorldHall / LessonMap / GameCollection / ChallengeHall
  GameScreen → GameplayAdapter + HUD + CoachDock
  Pause / Guide / Settings / Result / Import
GameplayAdapter
  LessonSpec + ModeSpec + ThemeKit → arena presentation
ProfileStore (已有课程ID、训练/挑战记录保持兼容)
```

UI不在每帧创建样式或重载纹理；状态变化通过信号通知HUD。建设与打字使用独立输入上下文，原版已存在的快捷键先纳入统一映射再扩展。世界ID只作为外观偏好新增字段；旧存档缺失时默认royal，不迁移词库ID。

## 5. 顺序与完成标准

1. **Core + 皇家垂直切片**：大厅→F/J课程→选城防→建塔→一波敌人→结算；真实词牌、全键盘、减少动态同时验证。
2. **同构五皮肤**：同一个主界面/资产页/奖励弹窗换五主题，验证语义、焦点、明度与材质身份。
3. **十玩法适配**：逐款换背景、目标主体、命中特效和结算插画；课程判定不跟着重写。
4. **网页验证**：匹配引擎模板、字体覆盖、音频解锁、失焦暂停、浏览器存档与备份；打包成功后再给部署结论。

现有Godot十玩法继续可运行；本轮浏览器设计原型独立，不悄悄把静态界面当作真实游戏替换发布。

## 6. 可读性与键盘验收

- 1280×800、1440×900、1920×1080、1024×768逐页检查；另测文字125%/150%、16:9与16:10。
- 不用鼠标走完大厅→课程→游戏→指法→暂停→结果；城堡选基座、购买、升级、修复、开波均可用键盘。
- 模态Tab与Shift+Tab闭环；关闭还原焦点；最后一个词尾键不穿透激活结果按钮。
- 六类怪物剪影、同屏字牌、Boss蓄力、红绿色觉辅助分别检查；复杂局面中不能靠声音补救看不清的警报。
- 正文/按钮对比≥4.5:1；焦点≥3:1；目标词不被粒子、屏震或图片高光遮盖。
- 程序化占位、概念图、正式素材在manifest中分状态；静态素材不标成完整动画。

权重沿用输入建议：剪影20、材质光15、色彩15、世界身份15、UI一致15、可读性20。85分为候选门槛，功能否决项优先；至少两轮样张+实机审查后冻结。当前不填“已通过”虚假评分。
