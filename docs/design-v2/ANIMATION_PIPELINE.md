# 游戏动画生产：本机 Grok Build + Godot

2026-10-19。Grok Build 用于生成角色与场景的真实运动源片；Godot负责输入响应、精确时序、碰撞、伤害与UI。动画完成事件不决定玩家输入是否生效。

## 1. 工具职责

- Image Gen：制作和修订符合五世界规范的角色母版、分层静态素材。
- 本机Grok Build：图生视频动作源片，固定镜头、角色身份与落脚点；先单角色验证，再扩展同一族。
- FFmpeg：检查原生宽高/帧率、提取实际帧、绿幕去背、统一画布、打包图集。不得把静态图缩放伪装成生成动画，不通过补帧伪造帧率。
- Godot SpriteFrames/AnimatedSprite2D：角色与特效逐帧播放；AnimationPlayer：状态事件与关键帧；Tween：按钮、血条、奖励与短时程序反馈。

## 3. 每个动作的制作契约

一条源片只承担一个清楚动作。固定尺寸、朝向、光源、比例、锚点和安全留白；角色内部不能出现抠像背景色。idle要求呼吸可见但脚不滑，攻击要有预备/接触/恢复，hit不允许造型突变。生成图或视频不得包含目标词、HUD、血量和动态数值。

背景动画可动旗帜、炉火、水面，建筑与道路保持稳定。用于菜单或演出的视频可以有镜头，战斗精灵源片锁定镜头。动态皮肤与教程不得共用未经验证的移动图层。

Grok源片不是直接可上线的精灵动画；须检查首/中/尾、实际尺寸下的连续运动、双脚、盾牌硬度、手指数目、首尾循环跳变、alpha边缘与绿边。动作不合格就保留candidate状态，不以自动像素检查代替动作审核。

## 4. 本机调用

先确认`grok --help`。使用已有登录，不读取令牌、不改登录配置、不购买额度、不安装新插件。只提交一次，记录请求ID；等待同一任务，失败时依据真实状态恢复，不盲目重开。

```powershell
./tools/grok/generate-animation.ps1 -Image assets/animation-sources/royal-guard/seed-v001.png -PromptFile assets/animation-sources/royal-guard/idle-v001-prompt.txt -OutputDirectory build/animations/royal-guard/idle-v001
```

原片、CLI原始收据放`build/animations/`，由Git忽略。项目保留母版、提示词、压缩运行素材、精简任务状态与QA；不要把可能包含base64的大收据提交进仓库。

```powershell
python tools/grok/pack-animation.py --video build/animations/royal-guard/idle-v001/grok-raw.mp4 --out assets/animations/royal-guard-idle-v002 --start 0.4166666666666667 --seconds 4 --cell 128
```

该工具保留选取区间的实际原生帧率，不插值；按同一画布缩放和锚点处理所有帧，不逐帧自动裁主体。本次原片8.041667秒与运行片4秒是不同交付，时长与帧数分别记录。默认128px图集只用于游戏尺度样片；更大显示须独立评估尺寸和内存。

## 5. 状态与预算

`seed → submitted → generated → normalized → qa_candidate → approved`。每一状态记录资产ID、世界、动作、参考图、源片任务ID、实际帧率、帧数、去背方式与缺陷；blocked或failed说明真实原因。

战斗只载入当前世界的必要图集，不将整段高清MP4当做每个单位的播放源。Web优先128/192px短图集并实测解码内存；减少动态时固定idle首帧，暂停时冻结播放时间。技能命中与键入优先即时生效，禁止为了等动画结束而丢按键。
