# 1.0 界面减负与游戏表现复核

2026-10-19。正式入口仍是打字训练和打字挑战，十种游戏共享同一课程与词库。这里记录实际实现与验证边界，不把设计目标当作已完成的人工验收。

## 视觉与交互

参考 Art Bible 2.0、Royal Fantasy Theme Kit、五世界令牌及生产模板；用户后续要求的明亮、轻松和低厚重感优先。统一上方柔光、圆润卡通材质、浅奶油与薄荷蓝绿、轻微按钮压下反馈和真实粗体标题。大厅使用新生成的学院场景，文字、数值、焦点和所有交互仍由 Godot 实时绘制。

删除侧栏宣传小字、训练页重复规则、卡片动作说明、场景底部长说明、重复连击面板、指法面板页脚及结算鼓励口号。任务卡从 306 缩到 252 像素，桌面首屏完整展示六项。保留输入样例、胜负条件、当前文字、下一键、词义和技能就绪状态；完整操作与指法收进 F1。错误提示只说明按键不符、进度保留。城堡战斗面板只展示资源、当前目标和连锁技能，移除常驻怪物说明书。

全程可用键盘。按钮最低 44 像素，主按钮更大；焦点进入任务卡时突出边框并播放该卡角色动作。列表随焦点滚动。弹窗隔离包括音量滑杆在内的焦点，关闭后恢复。设置中左右键调节音乐、音效音量；F2 全局静音。

## 素材与声音

- Built-in Image Gen：`academy-lobby-v10.png` 学院场景、`learning-sprites-v10.png` 六件透明基础训练道具；来源记录在素材旁。
- 本机 Grok Build：疾行兽、Boss、铁盾卫、萨满、爆破兵五条新源片。实测每条 720×720、24fps、193 帧、8.041667 秒。每种取 48 帧行走与 18 帧受击；不补帧、不逐帧重定位。Boss 使用 v10b 全画布安全留白，裁切不合格的候选未上线。源片原音轨不用于游戏，归档为无声 MP4。旧地鼠/UFO/赛车/哥布林动作只做透明边缘去杂色，保留原始文件。
- 14 个原创程序音效、两条同长度音乐分轨；Music/SFX/UI 分总线、音高轻微变化、键入限频和有限复音，连击提升节奏层，重要反馈压低背景音乐。原城堡元素音效继续使用。
- 音频已检查时长、峰值、非静音、无源文件削波、总线和静音/音量逻辑。尚无扬声器或耳机人工听音验收，不声称混音已通过专业听审。

## 内容与边界

709 个独立编写的核心训练词、24 生活主题、48 条原创短句沿用 0.9。参考 A1–A2 / Cambridge A2 Key 范围，没有指定的真题频次来源，不能称作经统计核验的“709 个历年真题高频词”。旧存档命名空间、版本和课程 ID 保留，音量字段允许旧档缺省。

本次是实际 Godot 游戏更新，非静态原型。自动规则检查、截图复核和浏览器键盘验证可证明行为与显示；不能替代儿童试玩、完整人工动画循环审查、听音及全设备性能验收。触屏和账号云同步不在当前实现内。
