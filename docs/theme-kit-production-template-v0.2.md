# Theme Kit 生产模板 v0.2（五世界独立型）

> 使用顺序：继承 Core → 填写 Theme Kit → 选择 Gameplay Adapter → 组合 Component → 样张验收。不得通过更换题材覆盖 Core 的核心形体及可读性规则。

## 五世界索引
- 皇家奇幻战争 `royal_fantasy`：英雄化王国战争、厚实城防、幽默物理表现，区别于童话。
- 科幻 `sci_fi`：圆角模块机械、能量科技。
- 现代 `modern`：微缩城市与友好工业。
- 古代 `ancient`：夸张古文明建筑与器物。
- 童话 `fairytale`：柔软有机、植物与魔法生命感。

## 3. 角色样张（每世界2个）
- A：重装防御者；B：轻型远程者。
- 两者共享原型的轮廓规则，题材符号不同。
- 交付：一句话人设、10张初步剪影→3张上色→1张定稿、正侧背视图、3/4视图、灰模、材质球、游戏实机镜头图、表情动作测试。
- 观察：48/96/192px 缩图仅为补充；最终按目标设备和真实镜头验证。

## 4. 场景样张（每世界1个）
- 结构：主要行动区 / 功能建筑区 / 外围叙事区。
- 交付：白盒、灰模、主视角昼光、战斗叠加图、暗部检查、热区/可交互区标注。
- 命题：同一通行逻辑或相似交互逻辑下进行主题转换，不复制固定地图形状。

## 5. 道具与建筑样张（每世界3个）
- 重要建筑1、功能道具1、奖励容器1。
- 交付：轮廓、近/远视图、材质拆解、可交互状态。

## 6. UI主题皮肤（每世界1组）
- 使用统一信息线框，只替换表层视觉：资源条、按钮、面板、卡片/槽位、图标、弹窗。
- 交付：完整主屏（或主操作屏）、角色/资产页、奖励弹窗以及主按钮6状态、2个资源图标、1套文字层级。
- 验收：不得修改主要操作语义；对比度、文案长度、多语言和点击热区需要测试。

## 7. VFX与动效（每世界2项）
- 普通反馈1 / 代表性技能1。
- 交付：关键帧、完整视频、截图序列、游戏实机录屏、色彩/亮度检查。

## 8. 统一输出格式
- 每个样张必须附：`ID / 世界 / 类型 / 角色功能 / 母风格继承项 / Theme覆写项 / 镜头 / 分辨率 / 审核状态 / 审核人 / 版本`。
- 源文件：分层概念稿、三维源文件与贴图、Figma或UI源工程、引擎预制体/动画特效工程。
- 对照：彩色、灰度、纯黑剪影、真实目标屏幕缩图、跨世界并排页。

## 9. 审核与冻结
- Royal Fantasy 专项：不得将通用母风格直接等同皇家战争题材；须与 Fairytale 可区分，且不复制参考游戏特定IP元素。
- Gate 1：剪影/灰模（失败则不进入材质）
- Gate 2：色彩/材质/光影一致性
- Gate 3：实机可读性与UI易用性
- Gate 4：跨世界并排审查与美术总监签字
- 例外：记录偏离原因、影响范围、回滚方案与审批人。
