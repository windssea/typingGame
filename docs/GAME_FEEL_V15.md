# 1.5 · 输入、接触与回弹

2026-10-20，按 game-feel 技能优化现有机制的反馈，不改变课程、难度、得分或存档。

## 反馈分工

- 十种玩法共用轻/中/重三级反馈。普通击键不震屏，普通命中收紧粒子，拳击/敲击与五连击、技能、Boss事件才强调冲击。即时冲击事件上限12，粒子上限280。
- 拳击逐字靠近准备，完成单词立即跨步接触，再以衰减回弹归位；调整拳套与冲击点距离。角色姿态停顿40/65毫秒，低重要性命中不强制停顿；按帧计算扣除时间余量，30/60/120 FPS结果一致。输入、敌人、技能、游戏计时保持正常。
- 气球破裂用缓出曲线迅速瘪下、再散去；地鼠命中收紧粒子，同一洞口的短暂命中反应不会与下一把预备锤叠加。
- 星桥机器人到达新落点时短暂压缩并回弹；单词输入中间键只有轻量能量反馈，完成词再集中喷射，避免每键都满屏粒子。
- 城堡冲击通过公共衰减模型表达，替换原来的高频抖动；普通击败为中档，Boss击败/震地为重档，受伤使用局部珊瑚色标记。没有新增全屏白闪。
- 泡泡、流星、极速沿用真实输入/发射事件接入公共反馈，保留更轻柔的常规节奏。五种Arcade技能拥有较强短冲击，但不阻塞键盘。
- 误按后正确重试立即清除错误色；错误音从-14 dB降至-22 dB。成功命中的音高随连击小幅上升，仍受独立音效音量与静音控制。复用已有音源，本轮没有生成新音效或声称完成耳机听感验收。
- 删除普通命中后反复出现的“命中/推进/重击”小白牌；只保留连击里程碑、格挡和漏过等必要反馈。输入词最后绘制，冲击线条和粒子避让文字保护区域。

## 减少动态与边界

已有“减少动态效果”设置统一取消冲击位移、移动粒子、喷射、落地压缩与爆裂运动；保留两个静止、短暂淡出的确认点。没有加入游戏控制锁定、物理击退、全局时间缩放或真实碰撞改动。角色继续使用现有本机Grok原生图集；没有新提交Grok任务。

`GameFeel`只存表现状态，不持有游戏模型。所有位移都在绘制层，目标坐标与输入匹配不随震动改变。玩家连续输入可以覆盖上一击演出，不要求等待动作完成。

## 验证

15组Godot无显示套件29716检查通过。新增180项检查涵盖：十种玩法的真实InputEventKey、演出期间输入、错误恢复、暂停、自动复位、时间缩放保持1、30/60/120帧姿态停顿余量及效果数量上限。原生OpenGL重跑手感180、文字/反馈192检查，其中8次像素比较确认粒子不影响词牌内部。Cloudflare两个打包测试通过。

旧测试将减少动态的数量写死为4，现改成上限4且速度为零，以验证无障碍行为而非固定实现数量。

[拳击接触与回弹采样](ui-review-v15/fighter-feedback.gif)是原生引擎受控采样：30张画面、每次推进表现20毫秒，再采样为25fps GIF；没有对Grok动画补帧，不是人工试玩成绩，也不是浏览器实时录像。原始截图为本机`build/v15-*-impact.png`，测试日志为`build/v15-regression-*`、`build/v15-native-*`。

发布与正式域名操作记录见 [验证记录](VALIDATION.md)。自动测试与原生采样不能代替儿童人工试玩、最终听感评审或低端设备性能验收。
