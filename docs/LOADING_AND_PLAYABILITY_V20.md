# 2.0｜按游戏加载与场景修复

## 加载原因和方案

旧版首屏需要完整下载 125,776,632 字节 PCK，其中动画纹理约 75.35 MB、背景与道具约 49.06 MB。原 PCK 的 gzip 体积仍有 125,013,947 字节，继续 gzip 无法解决大包下载。WASM 和 PCK 原本已并行下载，问题不是串行请求。

同一台电脑的浏览器采样，旧版菜单约 20.3 秒，早期分包版约 6.0 秒；加入全部词牌材质后的候选版约 9.1 秒。旧 PCK 下载约 16.1 秒，材质候选版约 2.0 秒；`callMain` 早期约 3.7 秒、材质候选版约 7.0 秒。引擎请求也受到缓存和网络状态影响，不能视为相同冷缓存基准或所有设备的固定加载时间。原始记录保留在本地 `build/load-audit/`。

Web 现在使用约 4.39 MB 的启动 PCK（gzip 约 3.92 MB），保留代码、字体、音效、菜单预览和必要 UI。选中小游戏后，异步下载该模式及其共享素材包。所有既有游戏内高清贴图和 Grok 帧动画均保留原始资源字节，不以菜单缩略图替代。

- 菜单预览单独导出，避免打开选择页就解码所有游戏动画。
- 共用素材分别为 learning、arcade、goblins、bosses；不会为皇家战下载整套城堡资源。
- 分包下载并行，显示真实已接收字节比例，支持 Esc 取消、网络失败后 Enter 重试。
- 下载后核对完整字节数和 SHA-256，再复制到引擎虚拟文件系统并挂载 PCK。
- CacheStorage 按内容哈希 URL 保存独立包；损坏缓存会从网络重新下载。存储不可用或配额不足时仍可游玩。
- 普通玩家存档沿用原路径和格式，原生版本继续使用完整本地资源。

首次访问仍需下载 Godot 引擎（gzip 约 10.05 MB）、启动包和加载页素材；“4.39 MB”仅指启动 PCK。第一次进入某个游戏也会有该模式的下载等待。R2 的正式 CDN 缓存可再通过资源自定义域名配置；当前收益来自分包，不将 `r2.dev` 的 immutable 响应头误写为 CDN 命中。

参考：[Godot 资源包挂载](https://docs.godotengine.org/en/stable/tutorials/export/exporting_pcks.html)、[Cloudflare R2 公共桶](https://developers.cloudflare.com/r2/buckets/public-buckets/)。

## 本轮玩法和画面

| 问题 | 实现 |
|---|---|
| 赛车与赛道错位 | 车辆、终点、喷气和粒子共用实际背景 cover 裁切坐标，分别对准图片中两条赛道。移除额外的旧坐标速度线。 |
| 哥布林输入后换词 | 完整词牌进入待命中状态，火球实际接触后才结算。普通哥布林/疾行兽一词击倒；装甲敌人存活时，命中后再显示下一词。 |
| 潜艇突然出现在中央 | 所有新潜艇从右侧屏幕外驶入；进入可玩范围前不提供可输入的词牌。 |
| 皇家敌人倒走 | 敌军朝向行进方向；每第六个敌人是大型统领，普通/高手/大师分别需要 3/4/5 次实际命中，有独立血量提示。 |
| 厨师半身、食材圆点 | 完整绘制原 Grok 角色帧，在台间走动；新生成九格食材/锅具/餐点图集，三个烹饪阶段都有正式贴图。 |
| 流星尾巴和炮位 | 新观测台场景、调整炮座与炮口；流星使用独立 CPUParticles2D 加法混合尾焰池，词牌偏向侧方且遮罩保护文字。 |
| UI 网页感和大底栏 | 场景坐标延续到 HUD 下方，使用边缘渐暗和薄金属线；移除浅色整块底栏、主界面角色背板和部分重复说明，重做格斗血条/VS 和技能区。 |
| 技能键不统一 | 街机与冒险技能统一空格；句子当前需要空格时，优先输入空格，不消耗技能。鼠标技能按钮继续可用。 |
| 词牌和字母纯色 | ImageGen 九种场景材质及珍珠金键帽，分别匹配皇家、太空、海底、嘉年华、木纹、赛车、拳击、厨房和竞速。九切片保持边角，文字描边、接受输入亮起、下一键光晕和错误颜色反馈均由引擎绘制。 |
| 输入位置来回闪现 | 保留跟随角色；全部场景目标字号不随选中切换，排序不随焦点重排，避让记忆上次相对锚点。取消字形、键帽和练习键的位移反馈；只改变颜色和边框光效。 |

## 验证方式

- 20 套原生/headless 回归，包含新增命中时序、屏幕外入场、统领多次命中、空格技能/句子冲突、实际道路坐标和原生拖尾检查。
- 独立启动 13 次：仅挂载启动 PCK 和该游戏声明的包，再创建实际游戏场景，检测缺失贴图、动画及错误依赖。
- Node 下载器测试覆盖按需依赖、缓存复用、损坏缓存、校验失败、取消、离线重试和缓存不可用。
- Python 打包测试确认游戏包不会混入 Pages，脚本加载顺序正确，CORS 保留正式域名。
- GPU 像素验证：真实光照、冲击波和流星粒子确实改变画面，同时词牌内部像素保持不变。
- 词牌稳定性回归：切换目标、正确/错误反馈、角色小幅移动和拥挤避让，检查相对锚点与重复排版无左右交替。
- UI 截图查看主页、课程、训练、挑战、设置和全部 13 个游戏。浏览器另行验证导出版本、R2 下载、空格技能、取消和缓存。

## 构建

```powershell
./tools/export-web.ps1 -Python <python.exe>
python tools/test-content-packs.py --source build/web-streamed
python tools/prepare-cloudflare.py --source build/web-streamed --out <new-output-directory> --project typinggame-cl5 --page-origin https://typinggame-cl5.pages.dev --asset-base-url <public-r2-origin>
./tools/deploy-cloudflare.ps1 -Package <output-directory> -ReuseEngine
```

可用 `-AssetsOnly` 先上传不可变资源，用本地页面验证真实 R2 链路后再发布 Pages。保留旧内容哈希资源，可回滚先前的 Pages 部署。
