# Royal Fantasy Warfare｜皇家奇幻战争 Theme Kit v1.0

> 定位：五世界独立型 Heroic Stylized 母风格中的独立题材套件。参考《皇室战争》的形体厚度、英雄化性格、幽默战斗和实体UI品质，但不复刻 Supercell 的角色、建筑、皇冠、卡牌框和具体战场。本文为原创游戏项目的建议规范，非官方品牌手册。

## 一、定位与设计边界
- **世界一句话**：一个由粗犷而可爱的守卫、工程师、射手和奇幻生物共同构成的热闹王国，充满竞技、冒险与夸张的物理喜剧。
- **核心情绪**：英勇、幽默、热闹、厚重、易接近。
- **区别于普通童话**：皇家战争偏城防、兵种、木石金属、物理力量与荣誉象征；童话偏植物、柔软曲线、生命感、魔法变化与梦幻氛围。
- **继承母风格**：清晰剪影、大体块优先、夸张功能装备、受控纹理、统一受光、立体按压反馈。
- **不继承原作专属IP**：原角色轮廓、皇冠标志、塔楼构型、卡牌模板、圣水图形、原始配色分区等均不得直接描摹。

## 二、角色DNA

| 原型 | 外轮廓 | 夸张焦点 | 性格表现 | 装备要素 |
|---|---|---|---|---|
| 原创王国重甲守卫 | 宽肩、短腿、稳定方圆形 | 巨型护盾、宽护肩 | 勇敢但有点笨拙 | 分段甲片、战盾、简化徽章 |
| 原创巡林弩手 | 上窄下稳、弩臂横向展开 | 大型弩、夸张手套 | 专注、灵巧 | 披肩、短靴、木弩 |
| 炼金术士 | 圆头、宽腰包、竖直药剂轮廓 | 试剂瓶、帽子 | 狡黠幽默 | 皮带、药瓶、手套 |
| 攻城工程师 | 低重心、大手、器械背负 | 大锤、工具包 | 热情可靠 | 厚皮革、工具、铆钉 |
| 奇幻盟友生物 | 球体/块体与极简小肢体 | 特殊脸或头饰 | 亲和、滑稽 | 主题挂件，不套用原作角色 |

**动作语法：** 预备夸张、主姿态强、打击有后坐、结束适度弹回；重装比敏捷型更有延迟和重量。**脸型语法：** 大眉弓、夸张鼻梁或胡须、清晰嘴型；细碎肌理与写实五官非重点。

## 三、场景与建筑DNA
- **基座**：高辨识厚石台基、木质平台；保留可通行轮廓。
- **主体**：圆润方块城墙、宽体塔楼、可识别入口与门楼。
- **功能件**：门、桥、箭孔、瞭望台、投射器、训练装置，以夸张轮廓表现功能。
- **装饰层**：旗帜、原创建制徽章、木桶、绳索、金属扣板，限制数量。
- **地表**：柔和石砖、大面积短草地、厚木板、清楚的路径色差。
- **空间层级**：主要交互区最安静，功能建筑中度复杂，外围堡垒轮廓可丰富。
- **镜头**：按玩法选择；不可把双通道对称塔战直接当成题材的固定规范。

**关键建筑示例：** “石砌瞭望塔”采用大块石质底座 + 厚实木石主体 + 超大瞭望口 + 原创尖拱护顶，不复刻原作公主塔/国王塔的标志性构型。

## 四、材质与色彩
- **建议主题色（非原游戏采样）**：主色 `#4365A0`，辅色 `#D7A857`，点缀 `#C76958`，面板 `#5D6575`，中性色 `#CEC5AF`。
- **材质组**：圆角石块（低频石材色块）、温暖木头（概括纹理）、宽高光金属（简洁反射）、厚织物旗帜、喷涂釉面。
- **光照**：柔和主光 + 适度环境补光 + 清晰接触阴影；宣传图可加轮廓光。战场不得被高对比环境装饰盖过角色。
- **标志物**：创造项目专属几何纹章，避免使用与参考游戏易混淆的皇冠与阵营标记。

## 五、UI 皮肤 DNA
使用母系统相同的交互骨架与Tokens（间距、信息层级、语义状态、热区、无障碍规则），只替换主题视觉：

| 组件 | Royal Fantasy 皮肤 | 不可改变的功能 |
|---|---|---|
| 主按钮 | 圆角厚板、釉面彩色内芯、压印金属边 | 操作优先级、按压状态、文本可读性 |
| 信息面板 | 石/木/金属的层叠边框、少量铆接 | 信息布局、关闭路径、背景对比 |
| 角色展示容器 | 防护盾形状的原创结构/矩形肖像窗 | 主视觉面积、等级属性层级 |
| 资源槽 | 木质或金属托槽、立体资源符号 | 数字易读、用途明确 |
| 奖励弹窗 | 原创奖章和宝匣，短促弹跳反馈 | 不阻碍主要动作、焦点清晰 |
| 图标 | 大块体积极简对象、高光方向统一 | 类别、状态、可点性明确 |

**避免：** 逐像素复制原作卡牌轮廓、皇冠奖杯、紫色圣水指示器及其UI位置布局。允许出现通用中世纪元素，但视觉组合必须原创。

## 六、道具、VFX与动作
- **道具**：厚实木桶、原创补给箱、铁砧、训练假人、战旗、城防投射机；突出功能轮廓。
- **特效**：几何冲击星、块状尘雾、清爽火焰、短弧雷电；持续时间依据真实战斗节奏验证。
- **动画**：站立微重心变化、夸张攻击预备、着地压缩、战后庆祝；避免夸张过度导致判定难以阅读。

## 七、Royal Fantasy 样张包（9项）
1. `ROY-CH-01` 原创王国重甲守卫：剪影3稿、三视图、3/4英雄稿、游戏镜头、灰模和材质。
2. `ROY-CH-02` 原创巡林弩手：同规格，验证轻量职业的形体差异。
3. `ROY-ENV-01` 王国训练庭院：白盒、昼光、功能标注、游戏镜头。
4. `ROY-PROP-01` 厚石瞭望塔：灰模、材质、功能可视化。
5. `ROY-PROP-02` 攻城工具箱：功能道具、远近距识别。
6. `ROY-PROP-03` 王国战利品匣：开关状态、奖励反馈。
7. `ROY-UI-01` 通用角色详情/主界面/奖励弹窗皮肤：复用母系统布局与交互状态。
8. `ROY-VFX-01` 盾牌格挡反馈：轮廓和时序演示。
9. `ROY-VFX-02` 战旗冲击波：色彩、范围提示和动态展示。

**对照验收：** 与其他四套世界并排，先检查剪影、灰模、配色密度、材质、UI按压；再验证本世界能否仅通过服装建筑和装饰识别为“幽默王国战争”，而非普通童话。

## 八、验收否决条件
- 小尺寸下无法辨认角色职业、建筑功能或关键交互状态。
- 石材/金属/木材过于写实，细节噪点明显高于其余四世界。
- 使用了明显近似原作核心角色、塔楼、皇冠、卡面布局的视觉组合。
- 因皇家装饰导致UI文字、热区和操作逻辑不一致。
- 与童话Theme Kit无法在角色形状、文化元素和材质气质上区分。

> 色值和比例为探索起点，真正的规范应通过样张实机、跨世界混排与玩法测试后冻结。
